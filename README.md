# Hope of Living Website

## Project Overview
Hope of Living is a community-focused website intended to share information about the organisation, its services and ways for community members to make enquiries.

## Website Pages
- **Home:** Introduces Hope of Living.
- **About:** Provides information about the organisation.
- **Services:** Describes the services offered.
- **Enquiry:** Allows visitors to submit service-related enquiries.
- **Contact:** Provides a contact form for visitors.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Structure
- `index.html` – Home page
- `about.html` – About page
- `services.html` – Services page
- `enquiry.html` – Enquiry page
- `contact.html` – Contact page
- `css/style.css` – Website styling and responsive layout
- `js/script.js` – Form validation and interactive functionality
- `images/` – Website images
